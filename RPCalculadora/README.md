## Instrucciones

Modificando el código de xml-rpc crear una calculadora remota en donde el server debera realizar las operaciones.

## ¿Como usarlo?

Para poder usar esta calculadora, es necesario tener abierta 2 terminales con la ruta de la carpeta en donde tenemos este proyecto (Ya sea en Visual Studio o CMD):

- 1 terminal ejecutando el archivo **server.py**
```bash
python server.py 
```
- 1 terminal ejecutando el archivo **cliente.py**
 ```bash
python cliente.py 
```

Al momento de ejecutar el archivo server.py, este se encagara de realizar las operaciones que se ingresen dentro de la calculadora (cliente) mientras que al ejecutar el archivo cliente.py, este se conectara al server para poder realizar solicitudes de dichas operaciones en ingrese en la terminal.

En caso de querer salir de la ejeccución en la parte del cliente (calculadora) debemos escribir solamente **salir**. (Para salir de la terminal del server se ocupa ingresar Ctrl + C)
